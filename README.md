1. To generate certs: navigate in your terminal to the 'ssl' directory & use command 'bash cert.sh' - fill in the relevant details for your cert & press enter. Your cert will be generated inside the 'ssl/certs' directory. Don't forget to also install these certs onto your system - For example, on windows, the certificates should be installed into 'Trusted Root Certification Authorities < Certificates'.

2.  Once you have generated some certificates & installed them into your system, you will need to re-generate the dynamic.yml file. Navigate to 'ssl' directory and use command 'python3 dynamic.py' to regenerate the file. You will need python installed on your system for this to work. You can update this file manually, but for it to work correctly, it will need to be formatted specifically to include the certs inside the ssl/certs directory. For more information on updating the dynamic.yml file manually, please read https://doc.traefik.io/traefik/getting-started/configuration-overview/
